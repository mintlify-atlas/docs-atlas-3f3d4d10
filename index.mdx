Notify is the de-facto standard filesystem watcher for Rust, used by [Deno](https://deno.land), [rust-analyzer](https://rust-analyzer.github.io), [Zed](https://zed.dev), [mdBook](https://rust-lang.github.io/mdBook/), and many more. It wraps native OS APIs — inotify on Linux, FSEvents on macOS, ReadDirectoryChangesW on Windows, kqueue on BSD — and falls back to polling on any platform.

## Get started in three steps

<Steps>
  <Step title="Add Notify to Cargo.toml">
    ```toml Cargo.toml
    [dependencies]
    notify = "9.0.0-rc.5"
    ```
  </Step>
  <Step title="Create a watcher and watch a path">
    ```rust main.rs
    use notify::{recommended_watcher, RecursiveMode, Result, Watcher};
    use std::{path::Path, sync::mpsc};

    fn main() -> Result<()> {
        let (tx, rx) = mpsc::channel();
        let mut watcher = recommended_watcher(tx)?;
        watcher.watch(Path::new("."), RecursiveMode::Recursive)?;

        for res in rx {
            match res {
                Ok(event) => println!("event: {:?}", event),
                Err(e)    => println!("error: {:?}", e),
            }
        }
        Ok(())
    }
    ```
  </Step>
  <Step title="Handle events">
    Each `Event` carries a `kind` (`Create`, `Modify`, `Remove`, …) and a list of affected `paths`. Filter, debounce, or act on them however your application requires.
  </Step>
</Steps>

## Platform support

| Platform | Backend | Crate feature |
|---|---|---|
| Linux / Android | inotify | *(default)* |
| macOS | FSEvents | `macos_fsevent` *(default)* |
| macOS (alt) | kqueue | `macos_kqueue` |
| Windows | ReadDirectoryChangesW | *(default)* |
| FreeBSD 14.5+ | inotify | `freebsd_inotify` for cross-builds |
| FreeBSD (older), OpenBSD, NetBSD, iOS | kqueue | *(default)* |
| All platforms | Polling | Always available via `PollWatcher` |

<Note>
  The minimum supported Rust version (MSRV) is **1.88**. MSRV bumps are documented in the [changelog](https://github.com/notify-rs/notify/blob/main/CHANGELOG.md) and may occur in minor releases.
</Note>
